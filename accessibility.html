Accessibility

Accessibility Statement

NAV aims for WCAG 2.2 AA as the baseline for public web experiences.

Accessibility is treated as a product requirement. The site is designed around semantic headings and landmarks, keyboard access, visible focus, readable contrast, large touch targets, responsive layouts, and reduced-motion support.

Feedback

If something prevents you from using the site or understanding its content, email NAVfitnessBrand@gmail.com with the page, device/browser if known, and what you were trying to do.

Ongoing work

Accessibility should be retested as content, navigation, interactive components, and third-party integrations change.
