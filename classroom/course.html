Course reasoning loop

Assess → Explain → Prescribe → Monitor → Adjust → Refer

Every topic earns its place by helping a learner make a better training or coaching decision. Physical performance never determines the grade in the university-format curriculum.

How each week works

Learn → retrieve → observe → apply → return.

The detailed week pages follow the curriculum's backward-design structure instead of acting like lecture notes.

Learn

Objectives + core lessons

Start with a prediction, define why the concept matters, then work through concise lesson clusters and a worked example.

Do

Quiz + lab + assignment

Retrieval, observation, measurement, interpretation, and applied decisions are tested separately instead of collapsing everything into one score.

Return

Evidence + spaced review

Each week labels evidence limits, connects to course outcomes, and carries one important idea forward into the next week.
