# Hard to Kill detailed course weeks

Stable student-facing week routes live at `week-1/` through `week-10/`.

Each route renders from shared canonical data and must contain:

1. Essential question / hook
2. Why the concept matters
3. Measurable learning objectives
4. Topic map
5. Core lesson clusters
6. Worked example
7. Applied scenario
8. Evidence/source-confidence layer
9. Quiz, solo-gym lab(s), and applied assignment links
10. Spaced return / next-week connection

The pages reuse the existing full-course browser-local progress state. Opening or reading a week must not automatically mark mastery.
